# NEXUS Cognitive Recursive Core — CRC-R1 Foundation Design

## Goal
CRC-R1 is an authority-safe cognitive substrate that connects existing NEXUS organs through immutable cognitive state, reversible hierarchical memory, compositional program hypotheses, bounded future simulation, reward prediction error, recursive credit assignment, capability self-modelling and guarded continual consolidation.

It is not itself a claim of AGI.

## Design law
The central research hypothesis is: branching/recurrent computation becomes useful only when the system can assign downstream success or failure back to the experts, memories, hypotheses, program nodes and simulated branches that caused it.

Historical motivation is the contrast between R7.17 (recurrence/branching with no fresh Blind-30 gain) and R7.18 (evidence credit assignment with a measurable Blind-31 gain).

## Authority boundary
CRC-R1 may propose, rank, simulate, retrieve, learn reliability statistics and write provenance-preserving memory. It does not gain final external action authority. Core-weight mutation is never an online side effect.

## Memory
Levels are RAW → EPISODIC → SEMANTIC → CAUSAL → ABSTRACT → META. Every non-RAW record must retain transitive RAW provenance.

## Programs
The fixed rule basis exposed by HARD-OOS D is replaced with compositional AST nodes: ATOM, SEQUENCE, COMPOSE, IF, INHIBIT, TEMPORAL and COUNTERFACTUAL.

## Future Tree
Each branch carries expected reward, information gain, causal consistency, uncertainty, compute cost and risk. Search is explicitly bounded.

## Reward prediction error
RPE = observed reward - predicted reward. It is an engineering prediction-error signal, not a biological dopamine claim.

## Recursive cognitive credit
A CognitiveTraceGraph propagates outcome error backward through router choices, expert proposals, memory retrieval, program hypotheses, branches, proofs and answers. Leave-one-out counterfactual credit remains available when an evaluator exists.

## Self-model and metacontrol
The self-model tracks empirical capability reliability, credit, latency and calibration. It is operational self-knowledge, not personality or consciousness. Meta-control allocates compute from novelty, uncertainty and budget.

## Continual learning
FAST: raw/episodic memory. MEDIUM: semantic/causal consolidation, reliability and calibration. SLOW: core/router weight promotion only after frozen replay, provenance, regression and calibration gates.

## Scientific gate
Before FTX1, run ablations for learned routing, memory, compositional AST, Future Tree, RPE+credit, metacontrol and continual consolidation on fresh DEV/META-OOS/FAR-OOS suites. FTX1 remains sealed until architecture and thresholds are frozen.
