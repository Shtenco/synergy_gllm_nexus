## Architecture actually trained

Ω-1.3 replaces independent start/end span heads with bounded **candidate graph slots**. Every one- or two-word candidate argument is represented as a whole span; SUBJECT and OBJECT slots score those candidate graph nodes while a compressed two-layer bidirectional GRU supplies relation semantics.

The full frozen Stage A corpus was checked before training: all **228,000** non-abstain gold subject/object spans were representable by this candidate lattice.

The CPU training environment throttled sustained PyTorch processes. The canonical run therefore used mathematically continuous **resumable chunks**. Model weights, AdamW moments, the fixed epoch permutation, cursor, and best-dev snapshot were saved between fresh Python processes. This is one continuous 100K optimization pass, not five independently restarted trainings.

## Per-relation blind diagnosis

The blind result is strongly asymmetric:

- `owned_by`: relation accuracy 95.375%, but subject exact only 1.425%;
- `located_in`: subject exact 99.15%, object exact 100%, but relation accuracy 0%;
- `older_than`: subject exact 91.2%, object exact 100%, but relation accuracy 0%;
- `is_a`: subject exact 90%, object exact 100%, but relation accuracy 0%;
- `before`: relation accuracy 4.6%, argument transfer failed;
- `causes`: relation accuracy 0%;
- `abstain`: recall 0%.

This means Ω-1.3 learned useful argument construction but did **not** learn sufficiently invariant semantic relation representations across the intentionally surface-disjoint blind templates.

## Integrity note

Blind metrics were not used for checkpoint selection. However, several blind surface examples had been inspected during earlier engineering diagnostics of the Stage A corpus. Therefore this evaluation is held-out with respect to optimization/selection, but it should **not** be described as a pristine human-unseen blind benchmark.

## Research conclusion

Ω-1.3 solved a real Ω-1.2 failure mode: exact non-abstain graph construction is no longer identically zero, and the model can learn high-quality argument boundaries for several relations. The remaining bottleneck is semantic relation generalization across lexical paraphrases, plus temporal/causal role transfer and abstention.

The correct next step is **not 250K**. A new frozen blind suite should be created for the next generation before development, and the next cortex should learn relation semantics through paraphrase-invariant contrastive/graph objectives rather than merely scaling this same supervised template distribution.
