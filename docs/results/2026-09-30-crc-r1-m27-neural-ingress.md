# CRC-R1 M27 — Neural/Ollama Ingress Adapters\n\n**Date:** 2026-09-30\n\nM27 makes the safe ingress contracts usable by a real local Qwen/Llama-class model without giving that model authority.\n\nTwo adapters are added:\n- OllamaLanguageCortexBackend: strict JSON semantic atoms plus source offsets;\n- OllamaTaskCortexBackend: strict JSON TaskOpcode/operator/arguments plus source offsets.\n\nThe model does not supply trusted hashes. It only proposes start/end character offsets. NEXUS recomputes SHA-256 over the exact substring and the existing M11b/M24 gates verify the result.\n\nBoth adapters use temperature 0, JSON output mode and a verified model digest reference. Invalid JSON, invalid offsets or unknown opcodes fail closed inside the ports instead of crashing the conversation runtime.\n\nThese are runtime interfaces only. A strong model is still not activated because no verified Qwen/Llama payload has passed M9b admission.
