# NEXUS GLLM Ω-1 Provenance and Evidence Policy

**Repository:** `Shtenco/synergy_gllm_nexus`  
**Initial architecture date:** 2026-09-15

## Origin

NEXUS GLLM Ω-1 is a new graph-native model line derived conceptually from the broader NEXUS research program: persistent graph memory, small-world reasoning, world state, exact/symbolic reasoning and Russian-language structure.

The Ω-1 runtime in this repository is implemented as a new codebase. It does not embed Qwen, Llama, Mistral, GPT or another pretrained LLM as its language/cognition backbone.

## Evidence rules

Every technical claim must be tied to one of the following evidence classes:

- **unit:** deterministic unit/integration test;
- **dev:** disclosed development benchmark;
- **blind:** frozen benchmark not used to tune the evaluated system;
- **external:** named external benchmark with exact protocol;
- **theoretical:** architecture hypothesis, not empirical evidence.

A synthetic or internal score must never be described as an official external benchmark result.

## Training provenance

Synthetic records generated by `training.generate_synthetic` include:

- explicit generation seed;
- split label;
- record ID;
- task name;
- entity list;
- provenance string;
- SHA-256 split/corpus manifest.

The default generator uses different entity namespaces for train, dev and blind records to prevent direct entity-name memorization from being mistaken for transitive reasoning.

## Benchmark freeze policy

Before using a blind set for model selection:

1. generate the dataset;
2. write the JSONL artifact;
3. run `benchmarks.freeze_manifest`;
4. record seed and SHA-256;
5. never rewrite that frozen artifact after observing model results.

If the benchmark definition changes, create a new benchmark version rather than editing the old one.

## Checkpoint policy

A promoted checkpoint should record:

- git commit SHA;
- Python version;
- PyTorch version;
- random seed;
- model config;
- training-data SHA-256;
- checkpoint SHA-256;
- exact benchmark SHA-256;
- raw benchmark output.

## External teacher policy

Future experiments may use external models to produce candidate training traces, but such data must be explicitly labeled as teacher-generated and must not be confused with native NEXUS reasoning evidence.

No external teacher is required by Ω-1 inference.

## Current limitations

The current Russian compiler is a small, deterministic micro-world parser. The recurrent neural core exists and is trainable, but long-term graph mutation remains deterministic/policy-gated. The current synthetic benchmark covers a narrow transitive-reasoning distribution.

No AGI, general-language parity, or external SOTA claim is made for Ω-1 V1.
